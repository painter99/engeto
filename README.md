# Engeto QA Coursework

This repository preserves coursework from a software-testing course completed in 2024. It is a learning record, not a maintained software product.

## Contents

- `automated_test.py` — a small UI testing exercise using pytest and Playwright. It checks the Fedora Silverblue download page, including its title and selected links.
- `final_project_1.zip` — the final project report in PDF format, covering REST API testing: the assignment, test scenarios, test execution, a bug report, and screenshots. Contact credentials and IP addresses have been redacted from the report.
- `LICENSE` — licensing information for this repository.

## Notes

The files are kept as a record of the coursework. The test exercise may require additional local setup and dependencies that are not included in this repository.
